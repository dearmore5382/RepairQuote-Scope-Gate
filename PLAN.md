# RepairScope Build Plan

1. Lock product boundary, actors, lifecycle, observation schema, derivation precedence, and non-payable scope.
2. Implement the contract with jointly sealed baseline data, two-party reports, deterministic outcomes, replay protection, and retry-safe nondeterminism.
3. Run static, semantic, direct-mode, differential, and adversarial tests before deployment.
4. Build an English-only responsive dApp with the supplied logo, deployment lock, transaction journal, finalized receipt checks, and authoritative readback.
5. Freeze the exact source hash and post-deployment live matrix.
6. Stop and ask the user to deploy the reviewed source once all local gates pass.
7. After deployment, verify source parity and run the frozen live matrix before enabling frontend writes or publishing release evidence.
